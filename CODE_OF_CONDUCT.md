
# Code of Conduct

## Our Pledge

We aim to create a welcoming, respectful, and inclusive environment for everyone.

## Expected Behaviour

- Be respectful and polite.
- Welcome different opinions.
- Give constructive feedback.
- Respect other contributors.
- Avoid harassment and discrimination.

## Unacceptable Behaviour

- Personal attacks or insults.
- Harassment or discrimination.
- Sharing private information without permission.

## Reporting Issues

Report inappropriate behaviour to the repository owner through GitHub.

Contact: https://github.com/arpithamishra1-dot

## Scope

This Code of Conduct applies to project discussions, issues, and pull requests.
